# Job Application Form

A responsive and accessible job application form built with **HTML5 and CSS3** as part of the freeCodeCamp Web Development curriculum.

This project demonstrates semantic form design, native browser validation, responsive layouts, and interactive CSS styling using core front-end development techniques.

## Overview

The Job Application Form provides a structured interface for collecting applicant information. It emphasizes usability, accessibility, clean visual presentation, and maintainable code without relying on JavaScript.

## Features

- **Semantic HTML5** — Uses `<form>`, `<fieldset>`, `<legend>`, `<select>`, and `<textarea>` to organize form content.
- **Native Form Validation** — Uses built-in HTML attributes such as `required` and appropriate input types to validate entries in the browser.
- **Interactive CSS States** — Applies `:focus`, `:valid`, `:invalid`, `:checked`, and `:hover` for visual feedback.
- **Responsive Layout** — Uses CSS Flexbox to support flexible alignment across different screen sizes.
- **Accessible Form Controls** — Uses semantic markup and associated labels to improve usability.
- **Clean User Interface** — Maintains a consistent layout, clear input organization, and intuitive interaction states.

## Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Regalson001/Job-Application-Form.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Job-Application-Form
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Implementation Highlights

### Semantic Form Structure

Native HTML elements provide a logical organization for form fields, helping improve readability, usability, and accessibility.

### Native Validation

HTML validation attributes work with CSS pseudo-classes to provide browser-level input checks and visual feedback.

### Responsive Styling

CSS Flexbox provides flexible alignment and helps the layout adapt to different viewport sizes.

### Accessibility Considerations

The project emphasizes meaningful labels, semantic elements, visible keyboard focus, and recognizable input states.

## Learning Outcomes

This project provided practical experience with:

- Building structured forms using semantic HTML5.
- Implementing native browser validation.
- Styling interactive states with CSS pseudo-classes.
- Creating flexible layouts with CSS Flexbox.
- Applying accessibility principles to form design.
- Organizing a front-end project using a clear file structure.

## Limitations

This project focuses on the front-end interface. Without a connected backend or submission service, it does not persist applications, deliver submissions to employers, or manage recruitment workflows.

Native browser validation improves client-side input checking but does not replace server-side validation in a production application.
